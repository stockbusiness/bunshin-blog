# 操作マニュアル

TASKS H-6。完了条件は「**モニターが自力でオンボーディングを完了できる**」。

この文書は**モニターに渡すもの**。画面を見ながら順に進められるように書く。

---

## 0. これは何をするものか

**あなたの代わりにAIが記事を書き、あなたがLINEで「はい／いいえ」を答えると公開される**仕組みです。

| あなたがすること | システムがすること |
|---|---|
| 分身（記事を書く人格）を決める | 記事の構成を考える |
| 届いた提案に答える | 記事を書く |
| 案件を登録する | 承認されたものだけWordPressへ下書きする |

**承認していない記事が公開されることはありません。** ここが一番大事な約束です。

**ブログはあなたのドメインで動きます。** ドメインとサーバーの費用はご自身の負担です。

---

## 1. はじめの設定（10段）

LINEのメニューから「はじめの設定」を開きます。

**途中でやめて大丈夫です。** 次に開いたときは、続きから始まります。どこまで済んだかは画面が覚えているのではなく、**あなたが実際に登録したものから毎回わかる**ようになっています。

### 段1 LINEでログイン

画面が見えていれば済んでいます。

### 段2・3 同意

2つあります。読んでから押してください。内容は `docs/CONSENT.md` と同じです。

**やめたくなったら退会できます。** やめても、それまでのブログと記事は残ります。

### 段4 分身をつくる

**「分身」は記事を書く人格です。** 名前・一人称・文体・専門領域・読者像・収益の目標をここで決めます。

| 項目 | 何を書くか |
|---|---|
| 分身の呼び名 | あなたが見分けるための名前（例：節約の人） |
| 種類 | 自分そのまま／なりたい自分／作った人物 |
| 一人称 | 記事の文体が決まります（例：私、僕） |
| 専門領域 | **1つ以上必須。** 何について書く人かが決まります |
| 読者像 | 誰に向けて書くか |
| やめる条件 | **先に決めます** |

**「やめる条件」を先に決める理由。** 後から決めると、かけた時間に引きずられて「もう少し続けよう」を繰り返すことになります。

つくった直後は**下書き**です。詳細画面の「使い始める」を押すと使えるようになります。

**最初は1体だけです。** 参加から31日で2体目、61日で3体目が開きます。1体目で操作に慣れてから増やすためです。画面に「あと何日で開くか」が出ます。

### 段5 ブログの枠をつくる

分身1体につきブログ1つです。

### 段6 WordPress をつなぐ

**先に1つだけ確かめてください。** WordPress の **設定 → パーマリンク**が**「基本」以外**（「投稿名」を推奨）になっていること。

**「基本」だとつながりません。** WordPress が `/wp-json/` の入口を作らないためです。**記事のリンク（`/go/xxxxx`）も同じ理由で404になります**ので、ここで直しておいてください。

ブログのURLを入れて、**「WordPressで承認する」**を押します。自分のWordPressの画面が開くので、**「はい、承認します」を押すだけ**です。戻ってくれば接続は終わりです。

**パスワードを作ったり、コピーしたりする必要はありません。**

うまく開かないときは、その下の**「承認の画面が出ないとき」**を開いてください。WordPressの管理画面で**アプリケーションパスワード**を発行して貼り付けます。（ブログが `https://` でない、WordPressが古い、管理画面の場所を変えている、のいずれかだと承認の画面が開きません）

**繋いだら、必ず「接続をためす」を押してください。** 押すまでこの段は終わりません。繋いだだけでは、本当に投稿できるかが分からないためです。

**接続テストが通るまでが1つの作業です。** 通らないときは、画面に出た項目（権限が足りない、REST APIが無効など）を直してもう一度試してください。

### 段7 ジャンルを決める

何について書くブログかを決めます。**選ぶのは運営です。** 医療・投資・融資・保険・法律・就労は、誤った記事の影響が大きいため**この実験では扱いません。**

**希望はLINEでお知らせください。** 画面には、いま選べるジャンルと、選べない分野が出ています。

**先に段8（案件登録）を済ませてください。** 案件が1件も無いと、審査は必ず止まります。**順番どおりでなくて構いません** — はじめの設定はどの段からでも開けます。

**案件が1件だけだと「警告つきで通りました」と出ます。** これは正常です。止まってはいません。

### 段8 案件を登録する

紹介する商品・サービスを、ASPの管理画面から転記します。**1件から始められます。**

入れるのは、**案件の名前・ASPの名前・紹介先のページ・アフィリエイトリンク・成果になる条件・自分で使ったことがあるか**の6つです。報酬額は分かれば入れてください。

**「自分で使ったことがあるか」だけは省けません。** ここで記事の書き方が変わります。使っていないものを「使ってみました」とは書きません。

**「事実」の欄を埋めてください。** 価格・条件・機能を**1行に1つ**書きます。

> 月額1,480円
> 初期費用なし
> 違約金なし

**ここに無い数字は記事に書きません。** 空のままだと、書ける内容がとても狭くなります。あとから足せます。

**リンクの出し方（直リンクか、こちらを経由するか）は選べません。** ASPによって規約が違い、**誤ると成果が無効になる**ため、運営側が案件ごとに設定します。

### 段9 通知の曜日と時刻

提案が届く時間です。**1日1件まで**（最大2件）。

指定した時刻から**3時間の間**に届きます。ジョブの都合で数分ずれることがあるためです。その時間に送れなかった分は、**次の通知日に回ります。**

### 段10 リンク計測を入れる

**「リンク計測のファイルを受け取る」**を押すと `bunshin-go.php` の中身が画面に出ます。「コピーする」でコピーし、その名前で保存して WordPress の `wp-content/mu-plugins/` に置くだけです。有効化の操作は要りません。手順は `docs/WORDPRESS_SNIPPET.md`。

**トークンを貼る作業も、パーマリンクを保存し直す作業もありません。**

**中身が見られるのは押した直後だけです。** 閉じると見られなくなります。見失ったらもう一度押してください — ただし**押すと新しいものになり、すでに置いてあるファイルは効かなくなります。**

**入れないと、記事の中のアフィリエイトリンクが開けません**（404になります）。

## 2. 毎日すること

### 提案が届いたら

LINEに記事の提案が届きます。開いて、次のどれかを選びます。

| 選ぶもの | どうなるか |
|---|---|
| **承認** | WordPressに下書きが作られます |
| **修正を頼む** | 直した記事がもう一度届きます |
| **見送る** | 公開されません。記録は残ります |

**答えなくても記事が公開されることはありません。** ただ、**答えないまま7日たった提案は期限切れになります。** 溜め続けると、通知が届いた瞬間に何件も待っている状態になるためです。

### 記事を公開する

承認するとWordPressに**下書き**ができます。公開はWordPressの画面から行ってください。

---

## 3. 週に一度すること

LINEから「今週の結果」を送ってください。ASPの管理画面で見た**成果件数と報酬額**を入力します。

**この数字は自動で取れません。** ASPによって管理画面の作りが違うためです。実験の結果をまとめるのに必要な、いちばん大事な数字です。

---

## 4. 困ったとき

| 症状 | 見るところ |
|---|---|
| 提案が届かない | 「はじめの設定」の段9。曜日と時刻を確かめる |
| 記事のリンクが404 | `wp-content/mu-plugins/bunshin-go.php` が置かれているか。パーマリンクが「基本」でないか |
| WordPressにつながらない | まず**設定 → パーマリンク**が「基本」以外か確認。そのうえで段6の接続テストをもう一度 |
| 分身を増やせない | 画面に「あと何日で開くか」が出ます。待つか、使っていない分身を休みます |
| 記事の内容が違う | 「修正を頼む」を選びます。案件の「事実」を埋めると精度が上がります |

---

## 5. やめるとき

運営者へ連絡してください。**退会しても、ブログと記事は残ります。** 記録の持ち出しもできます。

WordPressのプラグイン（`bunshin-go.php`）は、退会後に外してください。外さないとリンクが404になります。
