# OPEN QUESTIONS

判断できない事項を記録する。**推測で実装しない。**

## 形式

```
### Q-001 タイトル
- 発生タスク：
- 状況：
- 選択肢：
- 影響範囲：
- 状態：未解決 / 解決（決定内容と日付）
```

---
